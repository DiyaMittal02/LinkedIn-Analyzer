# 🚀 LinkedIn Market Analyzer

A powerful market intelligence dashboard for job seekers and recruiters. This tool analyzes LinkedIn job data to identify high-opportunity roles ("Hidden Gems") with **high salaries** and **low competition**.

## ✨ features

### 1. 📊 Market Opportunity Matrix
*   Visualizes the entire job market in a quadrant scatter plot.
*   **X-Axis:** Competition (Views) | **Y-Axis:** Salary.
*   Clearly identifies "Hidden Gems" (Top-Left Quadrant).

### 2. ⚔️ Market Battle (New!)
*   **Head-to-Head Comparison:** Select any two job roles to compare them directly.
*   **Metrics:** Average Salary, Median Views (Competition), and Total Job Count.
*   Helps you decide which career path has better market conditions.

### 3. 🏆 Top Companies Leaderboard
*   Ranks companies based on an exclusive **Opportunity Score**.
*   Highlights companies that consistently offer high salaries with lower competition.
*   Uses a progress bar visualization for easy scanning.

### 4. 📈 Interactive Analytics
*   **Salary Benchmarker:** Compare a specific role's salary against the market average.
*   **Salary Distribution:** View histograms to see the realistic salary range for any role.

### 5. 📄 Smart Reporting
*   **Export HTML Reports:** Generate a full market report with embedded interactive graphs.
*   **Download Data:** Export filtered datasets for your own analysis.

## 🛠️ Tech Stack
*   **Framework:** [Streamlit](https://streamlit.io/)
*   **Data Processing:** Pandas, NumPy
*   **Visualization:** Plotly Express, Altair
*   **Data Storage:** Parquet (Optimized for speed)

## 🚀 How to Run Locally

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/DiyaMittal02/LinkedIn-Analyzer.git
    cd LinkedIn-Analyzer
    ```

2.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the app:**
    ```bash
    streamlit run app.py
    ```
